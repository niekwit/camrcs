==============
Requirements
==============

``camrcs`` requires a Unix-based operating system with Python 3.14 or later and Bash installed. The Python dependencies will be installed during installation with `pip`.

The following non-Python tools are also required:

* `pigz <https://zlib.net/pigz/>`_ (see :doc:`installation`)
* ``rsync``
* ``tar``, ``split`` and ``md5sum``
