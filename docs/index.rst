Welcome to camrcs's documentation!
====================================

``camrcs`` is a Python package that can upload or retrieve data to/from Cambridge University's `Research DataVault (RDV) <https://docs.hpc.cam.ac.uk/storage/rdv/index.html>`_ and `Research Cold Storage (RCS) <https://www.hpc.cam.ac.uk/research-cold-store>`_.
